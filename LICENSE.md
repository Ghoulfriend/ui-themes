# Theme License

This repository shares community-created UI themes for the HDOS client.

## Community artwork

Theme creators allow others to use, share, and modify the original artwork
and changes they contribute, provided they are credited.

Each theme's README must name its creator and credit any other assets it uses.

## Old School RuneScape assets

Old School RuneScape sprites, interface artwork, names, and other game content
belong to Jagex. They are not licensed by this repository or by theme creators.
Their use remains subject to Jagex's Fan Content Policy and applicable game
terms.
